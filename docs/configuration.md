# پیکربندی شیرازه

شیرازه دو لایه پیکربندی دارد که مخاطبانشان متفاوت است:

| لایه | پرونده | برای چه کسی؟ | چه چیزی را؟ |
|---|---|---|---|
| **فنی (مونتاژ برنامه)** | `bootstrap.json` | سازنده/توسعه‌دهنده | فهرست افزونه‌ها، آداپتورها، نسخه هسته |
| **کاربر** | `config/config.js` | شما، نگارنده مستندات | ظاهر و نحوه استفاده |

این راهنما درباره لایه دوم است. `bootstrap.json` را فقط وقتی دست بزنید که می‌خواهید افزونه‌ای اضافه یا کم کنید.

## config/config.js

پرونده‌ای اختیاری در پوشه `config/`. اگر نباشد یا خطای نگارشی داشته باشد، شیرازه با پیش‌فرض‌ها بالا می‌آید و خطا را در کنسول مرورگر گزارش می‌کند. هر کلیدی که ننویسید، پیش‌فرض خودش را نگه می‌دارد. کلید ناشناخته فقط یک هشدار می‌گیرد — چیزی خراب نمی‌شود.

```js
export default {
  language: 'fa',
  theme: 'light',
  docsRoot: './docs',
};
```

## کلیدهای پشتیبانی‌شده (0.2.0)

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `language` | `'fa'` | زبان پیش‌فرض رابط (`'fa'` یا `'en'`) |
| `direction` | `'rtl'` | جهت رابط (`'rtl'`، `'ltr'` یا `'auto'`) |
| `theme` | `'light'` | تم رنگی |
| `docsRoot` | `'./docs'` | پوشه پرونده‌های مارک‌داون نسبت به ریشه سایت |
| `homePage` | `'README.md'` | پرونده‌ای که برای مسیر `/` نمایش داده می‌شود |
| `sidebarFile` | `'_sidebar.md'` | پرونده فهرست navigation |
| `toc` | روشن، عمق ۳ | پنل «در این صفحه» — `{ enabled: true, maxDepth: 3 }` |
| `extensions` | همه روشن | فعال/غیرفعال کردن دستور پارسنشان — شیءای با کلیدهای `admonitions`، `persianList`، `persianPoem` و `persianFootnote` (هرکدام `true`/`false`) |

مثال خاموش‌کردن شعر و جعبه‌ها:

```js
export default {
  extensions: { admonitions: false, persianPoem: false },
};
```

## امنیت لایه کاربر

مقادیر این پرونده فقط در بخش‌های مجاز (رابط کاربری و افزونه مستندات) اعمال می‌شوند؛ کلیدهای فنی مثل فهرست افزونه‌ها یا آداپتورها از این مسیر قابل تغییر نیستند و نادیده گرفته می‌شوند.

## نقشه راه

کلیدهای بیشتری در نسخه‌های بعدی اضافه می‌شوند: `appName`، `logo`، `favicon`، `toc`، `codeCopy`، `title`، `notFoundPage`، `extensions`.
