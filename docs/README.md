# شیرازه

**شیرازه** یک مستندساز وب است: پوشه‌ای از پرونده‌های مارک‌داون را به یک سایت مستندات زنده تبدیل می‌کند — بدون ساخت، بدون پایگاه داده، فقط پرونده‌های استاتیک.

این پروژه روی [معماری بنیان](https://github.com/barnevis/bonyan) و چارچوب [پی](https://github.com/peyjs) ساخته شده است.

## چرا شیرازه؟

- **بدون ساخت** — مارک‌داون را بنویسید؛ مرورگر آن را رندر می‌کند.
- **قرار دادن آسان** — خروجی یک پوشه استاتیک است؛ روی هر میزبانی کار می‌کند.
- **معماری افزونه‌ای** — هر توانایی یک افزونه بنیان است و می‌توانید جایگزینش کنید.
- **فارسی‌محور** — جهت راست‌به‌چپ و فونت فارسی از ابتدا در نظر گرفته شده است.

## شروع سریع

1. پوشه `docs/` را با پرونده‌های مارک‌داون خود پر کنید.
2. فهرست navigation را در `config/sidebar.md` بنویسید.
3. کل پوشه را روی هر میزبان استاتیک قرار دهید. تمام!

برای جزئیات بیشتر، [راهنما](guide) را ببینید.
