# نوشتن مارک‌داون

شیرازه از مارک‌داون استاندارد به‌همراه GFM پشتیبانی می‌کند.

## تیترها

هر تیتر به‌طور خودکار شناسه پایدار می‌گیرد و از طریق پیوندهای درون‌صفحه‌ای قابل دستیابی است.
