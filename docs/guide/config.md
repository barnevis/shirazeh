# پیکربندی

کل پیکربندی شیرازه در پرونده `bootstrap.json` در ریشه پروژه قرار دارد.

## افزونه‌ها

ترتیب افزونه‌ها در بخش `plugins` مهم است؛ افزونه‌های زیرساختی (مثل مسیریاب) باید پیش از دیگران بیایند.

## پیکربندی هر افزونه

مقادیر پیش‌فرض هر افزونه در بخش `config` با نام افزونه به‌عنوان کلید بازنویسی می‌شود:

```json
{
  "config": {
    "shirazeh.docs": {
      "docsRoot": "./docs",
      "homePage": "README.md"
    }
  }
}
```

## زبان و جهت رابط

زبان پیش‌فرض رابط در `config.ui.language` تعیین می‌شود و کاربر می‌تواند از نوار بالای صفحه آن را عوض کند.
