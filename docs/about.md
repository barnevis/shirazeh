# درباره معماری

شیرازه روی **معماری بنیان** ساخته شده؛ معماری افزونه‌ای بدون وابستگی به فریم‌ورک.

## لایه‌ها

1. **میزبان اجرا** — پیکربندی، محیط و بارگذاری ماژول را فراهم می‌کند.
2. **هسته** — ثبت سرویس‌ها، گذرگاه رویداد و چرخه حیات.
3. **افزونه‌ها** — زیرساخت، محصول، ویژگی، سکو و انتقال.
4. **لایه رابط کاربری** — نمایش و تعامل، بدون منطق محصول.
5. **آداپتورها** — مرز با فناوری‌های بیرونی.
