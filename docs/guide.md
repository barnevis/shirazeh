# راهنمای شیرازه

در این بخش با اجزای شیرازه و نحوه کار آن آشنا می‌شوید.

## چه چیزی در پوشه docs قرار می‌گیرد؟

| پرونده | نقش |
|---|---|
| `README.md` | صفحه نخست سایت |
| `_sidebar.md` | فهرست navigation کنار صفحه |
| هر پرونده `.md` دیگر | یک صفحه مستندات |

## نشانی صفحات

نشانی هر صفحه از مسیر نسبی پرونده آن به‌دست می‌آید:

- `docs/guide.md` ← `/#/guide`
- `docs/guide/markdown.md` ← `/#/guide/markdown`

از صفحه بعدی شروع کنید: [نوشتن مارک‌داون](markdown)
